# Internacionalização (i18n)

Idiomas: pt-BR (fonte), es-ES e en-US. Arquivos em `frontend/src/i18n/locales/`. O idioma ativo vem do seletor do cabeçalho (salvo em `localStorage`, ou do navegador na primeira visita); `<html lang>` e o título da aba acompanham o idioma.

## Regras

1. **Nenhum texto fixo.** Todo texto visível passa pelo i18n: conteúdo de template, `aria-label`, `title`, `placeholder`, props de texto (`titulo`, `descricao`, `acao`) e textos montados em JS (legendas, tooltips, mensagens de erro). Ficam de fora os dados (nomes de candidatos, partidos, municípios e UFs) e os tokens que não se traduzem (`BU`, `UF`, `SHA-256`, `LOF`, `MAD`, `IF`, símbolos, números). O teste `tests/i18n-texto-fixo.test.js` varre os templates e falha com texto fixo; a lista de exceções está no próprio teste.
2. **Chaves e paridade.** Os três locales têm exatamente as mesmas chaves, os mesmos placeholders e as mesmas formas de plural; toda chave usada no código existe e nenhuma chave existe sem uso (`tests/i18n-chaves.test.js`). Chaves montadas dinamicamente usam um prefixo literal (por exemplo, `` `regiao.${nome}` ``) para que o teste as reconheça.
3. **Plural.** Contagens usam mensagens com `|` (`unidade.*`): `$t('unidade.secao', n)`; com variáveis, `$t('chave', { n }, n)`.
4. **Textos da API por código.** O frontend traduz avisos e erros pelo `codigo` que a API envia; a `mensagem` da API só aparece quando o código é desconhecido.
   - Avisos: `avisos.mensagem.<CODIGO>` (`lib/status.js`, `avisoMensagem`) e o rótulo `avisos.<codigo>`.
   - Erros: `erros.codigo.<CODE>`, `erros.naoEncontrado.*` (`NOT_FOUND`, discriminado pela mensagem do backend) e `erros.falhaConsulta` (`lib/erros-api.js`, usado por `ApiError`).
   - O valor em pt-BR é a mensagem atual do backend, sem alteração. Código novo no backend exige a chave nos três locales (`tests/i18n-codigos-api.test.js` confere os códigos do backend).
5. **Formatação pelo idioma ativo.** Números, percentuais, datas e horas usam o locale ativo do vue-i18n (`lib/format.js`), reativamente; o fuso continua `America/Sao_Paulo`. Os eixos e legendas dos gráficos usam os mesmos formatadores.
